Sync analyses to a Google Sheet

Render's free tier wipes the on-server log every time the service restarts. For permanent cross-user history, point this site at a Google Sheets Apps Script webhook — every analysis will append a row to your sheet automatically.

  1. Open a Google Sheet → Extensions → Apps Script.
  2. Paste this code, save, then Deploy → New deployment → Web app (Execute as: Me · Access: Anyone).
    function doPost(e){
  const sh=SpreadsheetApp.getActive().getSheetByName('Analyses')
    ||SpreadsheetApp.getActive().insertSheet('Analyses');
  if(sh.getLastRow()===0)sh.appendRow(['Date','Sales Rep','Client','Status',
    'Go-Live','Total','Core','Adj','Seg','Exp','OOC','NC','Spend','Svc %','ID']);
  const d=JSON.parse(e.postData.contents);
  sh.appendRow([d.date,d.salesRep,d.clientName,d.clientStatus,d.goLive,
    d.total,d.core,d.adjacent,d.segmented,d.expansion,d.outOf,d.nonComp,
    d.totalSpend,d.serviceablePct,d.analysisId]);
  return ContentService.createTextOutput(JSON.stringify({ok:true}));
}
  3. Copy the deployment URL.
  4. On Render → Service → Environment → add variable SHEETS_WEBHOOK_URL = the URL above, then redeploy.

Once set, every analysis runs POST /api/log here, which forwards to your sheet. The sheet becomes the durable source of truth.
